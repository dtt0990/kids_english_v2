T&T English Advanced
Academic & Communication Foundation for ages 8 to 12

FILES
index.html       Main interface
curriculum.js    Curriculum content
app.js           App logic, audio, recording, progress and review

GITHUB PAGES
1. Upload all three files to the root of one GitHub repository.
2. Open Settings > Pages.
3. Publish from the main branch and root folder.
4. Use the generated HTTPS link as the app link.

DATA
Progress is stored in localStorage.
Use the same device and the same browser to keep progress.
Avoid private browsing and do not clear site data if you want to keep progress.

AUDIO
Vocabulary, collocations, sentence patterns, grammar examples, reading passages and speaking models include browser voice playback.
The learner can select an available English voice in Profile.
Speaking recording uses the microphone and works best from the HTTPS GitHub Pages link.

CURRICULUM
16 advanced topics
4 stages
3 study days per topic
4 adaptive levels for ages 8 to 12
Bilingual support
Vocabulary, collocations, grammar, listening, reading, speaking, writing and academic skills
